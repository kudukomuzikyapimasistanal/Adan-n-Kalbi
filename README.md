ADANIN KALBI - Windows EXE paketi
1) https://nodejs.org adresinden Node.js (LTS) kur.
2) Bu klasoru Windows'ta ac.
3) build.bat'a cift tikla -> dist klasorunde tek dosyalik "Adanin Kalbi 1.0.0.exe" olusur (kurulum gerekmez).
   Sadece denemek istersen calistir.bat'a cift tikla.
Oyun icinde F11: tam ekran. Internet baglantisi yalnizca ilk kurulumda gerekir.
